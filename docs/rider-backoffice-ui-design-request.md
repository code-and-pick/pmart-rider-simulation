# 라이더 백오피스에 라이더 시뮬레이터 화면 모양 입히기 — 요청서

- 쓴 날: 2026-11-21, 라이더 시뮬레이터 세션(PC 5)
- 받는 곳: 라이더앱 세션(라이더 백오피스 `pmart-clients/web/rider-backoffice` 담당)
- 사용자 지시(2026-11-21): "백오피스가 통합, 라이더, MFC, 인사 이렇게 나눠져 있는데 UI를 통일시키려고 하거든. 일단 라이더 백오피스에만 라이더 시뮬레이션 UI 적용시켜봐. **기능이나 안에서 볼 수 있는 정보, 내용은 바꿀려면 허락받고.**"

## 0. 꼭 지킬 것

1. **라이더 백오피스만 바꾼다.** `web/ui/src/console.css` 는 통합 백오피스·MFC·인사가 같이 쓰므로 고치지 않는다. 라이더 백오피스 쪽 파일(`web/rider-backoffice/src/index.css` 에서 `console.css` 를 읽은 **뒤**에 읽는 새 파일, 예: `src/sim-look.css`)로만 덮는다.
2. **겉모양만 바꾼다.** 색, 글꼴, 선, 둥글기, 상태 표시 모양, 간격이 대상이다.
3. **사용자 허락이 먼저인 것:** 기능, 화면에 보이는 정보, 문구, 메뉴 구성, 누르는 방식이 바뀌는 것. §4 에 따로 모아 두었다. 사용자에게 묻고 "해" 라는 답을 받은 것만 한다.
4. `docs/apps/backoffice-ui-guide.md` 는 지금 AWS 콘솔 모양을 기준으로 삼고 있다. 이번 일은 **라이더 백오피스에서 먼저 시험해 보는 것**이므로, 그 문서 "적용 현황"에 "라이더 백오피스는 라이더 시뮬레이터 모양 시범(사용자 2026-11-21)"이라고 적어 두기만 한다. 다른 백오피스는 그대로 둔다.
5. 보라색은 쓰지 않는다(사용자가 싫다고 함).

## 1. 비교한 것

라이더 백오피스(https://192.168.0.40:8446)는 다크 화면에서 보기만 했다. 누르거나 저장한 것은 없다. 본 화면은 대시보드, 라이더 관제, 라이더 찾기, 배송 찾기, 상담함, 수행료 조정이다.

|---|---|---|
| 바탕색 | 따뜻한 갈회색(`#141311` / 판 `#1c1b19` / 선 `#3a3835`) | 푸른 기 도는 짙은 회색(`#0b0d10` / 판 `#14171c` / 선 `#23272e`) — 선이 덜 튀고 숫자가 또렷함 |

## 2. 색 토큰(그대로 가져가면 됨)

## 3. 바꿀 곳(겉모양만 — 바로 해도 됨, 효과 큰 순)

### ① 색 토큰 바꾸기(§2)
갈회색이던 바탕이 짙은 회색과 얇은 선으로 바뀌고, 강조 파랑이 `#4c8dff` 가 된다. 화이트도 같은 결로 맞춘다. 이 하나로 첫인상이 가장 크게 바뀐다.

### ② 상태 표시를 "● 글자"로
- 라이더 찾기(운행·제한·가입 승인 칸), 배송 찾기(수행 상태), 상담함(상태·기다린 시간), 라이더 관제 목록의 동그라미 아이콘(⊙ ✓ ⊗)을 **작은 점(7px) + 글자**로 바꾼다.
- **정상·자동 승인·운행 끝** 같은 평상시 값은 보조 글색(회색)으로 둔다. 색은 문제(빨강)·주의(주황)·진행 중(파랑)에만 쓴다. 한 줄에 색이 여러 개 켜지지 않게 한다.
- 글자는 바꾸지 않는다. 아이콘만 점으로 바꾸는 것이다.

### ③ 문제 줄은 왼쪽 띠로
- 라이더 관제 "라이더 목록"의 끊김·위치 없음 줄은 지금 빨강 바탕에 빨강 테두리다. 이것을 **왼쪽 3px 빨강 띠 + 빨강 점**으로 바꾸고 바탕은 판 색으로 둔다.
- 다른 화면에서도 줄 전체나 칸 전체를 빨강·주황으로 칠한 곳은 같은 방식으로 바꾼다(상담함 "열림" 줄 등).

### ④ 판 둥글기 10px, 그림자 없음
지금 `console.css` 가 2px 로 깎는 규칙(`main :is(.rounded-lg …)`)을 라이더 백오피스 파일에서 `--radius-box: 10px` 로 되돌린다. 입력칸과 단추는 6~8px 로 한다.

### ⑤ 고른 칩·탭 조용하게
"전체 / 이용 중 라이더 / 모두 / 모든 상태 / 가입 최근 순" 같은 고른 칩이 파랑으로 꽉 채워져 있다. 이것을 **옅은 판 바탕(`#1b1f25`) + 파랑 글자 + 1px 파랑 테두리**로 바꾼다. 상담함의 "상담 중 / 끝남 / 소명·이의" 탭은 밑줄 2px 로 이미 조용하니 그대로 둔다.

### ⑥ 숫자
- 숫자 카드, 표의 시각·건수·금액은 `font-variant-numeric: tabular-nums` 로 한다.
- 숫자 카드에서 값이 0 이면 보조 글색으로 낮춘다. 값이 있을 때만 본문 색이고, 주의 값만 주황·빨강이다. 대시보드는 이미 이렇게 되어 있으니 라이더 찾기·배송 찾기·상담함 카드도 같게 맞춘다.
- ID와 센터 코드(`MFC-SEED-01`, 배송번호)의 모노 글꼴을 Pretendard + 고정폭 숫자로 바꾼다.

### ⑦ 다크 화면 지도
라이더 관제 지도 타일 그림에만 `filter: brightness(0.98) saturate(0.9)` 를 건다. 라이더 핀과 이름표에는 걸지 않는다. 반전(invert)은 쓰지 않는다.

### ⑧ 표
- 머리는 보조 글색 600, 판과 같은 바탕, 아래 1px 선으로 한다.
- 줄 사이 선을 `#23272e` 로 하고, 줄에 마우스를 올리면 옅은 판 색이 되게 한다.
- 지금 쓰는 줄 높이(약 38px)는 그대로 둔다.

### ⑨ 화이트 모드
같은 토큰의 화이트 값을 쓴다(§2). 머리 줄과 왼쪽 메뉴도 흰 바탕에 선 하나로 나눈다. 테마를 바꾸는 단추(머리 줄 ☀)의 동작은 그대로 둔다.

## 4. 사용자 허락이 먼저인 것(하지 말고 물어보기)

라이더 시뮬레이터에서는 아래처럼 바꿨지만, 백오피스에서는 기능이나 보이는 내용이 바뀌는 일이다. **사용자에게 하나씩 묻고, 허락받은 것만 한다.**

- **a. 화면 안내 상자·긴 부제 줄이기.** 상담함과 수행료 조정의 "화면 안내" 글머리 상자, 각 화면 제목 아래 긴 설명을 짧게 하거나 접는다. 시뮬레이터는 "설명 글을 붙이지 말고 화면을 보면 알게" 하는 쪽이다. 문구가 바뀌므로 허락이 필요하다.
- **b. 검색 조건 상자를 "찾기 칸 + 깔때기 팝업"으로.** 라이더 찾기와 배송 찾기의 칩 여러 줄짜리 검색 조건을, 시뮬레이터 운영 현황처럼 왼쪽 찾기 칸 + 깔때기 단추(누르면 상태 고르기 팝업) + 고른 것 칩으로 바꾼다. 누르는 방식이 바뀐다.
- **c. 숫자 카드를 거르기 단추로.** 라이더 찾기의 "운행 중 4", 배송 찾기의 "미배정 1" 카드를 누르면 그 상태로 걸러지게 한다. 기능 추가다.
- **d. 목록 줄을 누르면 아래로 펼쳐 상세.** 배송 찾기에서 줄을 누를 때 다른 화면으로 가지 않고 그 줄 아래에 상세를 펼친다. 시뮬레이터는 사용자가 "정신 사납게 넘어가지 말고 바로 아래에"라고 해서 이렇게 바꿨다. 누르는 방식이 바뀐다.
- **e. 왼쪽 메뉴 모양.** 시뮬레이터는 72px 아이콘 메뉴지만, 백오피스는 메뉴가 많으므로 **지금의 글자 메뉴를 그대로 두는 것을 권한다.** 바꾸려면 묻는다.
- **f. 머리 줄의 역할 칩(CS_AGENT, HR_ADMIN …)과 "시뮬레이터 ↗" 링크.** 보이는 정보이므로 그대로 둔다.

## 5. 하지 말 것

- `web/ui/src/console.css`(공용)를 고치는 것. 통합·MFC·인사 백오피스가 같이 바뀐다.
- 보라색, 줄이나 칸 전체를 빨강·주황으로 칠하는 것, 그림자.
- 설명 글을 더 붙여서 해결하는 것(시뮬레이터 원칙).
- 화면 문구, 표 칸, 메뉴 이름을 바꾸는 것(§4 허락 전).

## 6. 라이더 시뮬레이터에서 볼 곳(읽기 전용)

- 화면: http://localhost:5181/?mode=http. 같은 PC 개발 서버이고, 다크·화이트는 왼쪽 메뉴 맨 아래에서 바꾼다. 운영 현황, 분석, 라이더 관제를 보면 된다.
- `src/ui/theme.css`: 토큰, 판, 상태 "● 글자"(`.rb-badge`), 문제 줄 왼쪽 띠, 숫자 카드, 다크 지도 필터, 화이트 모드. 머리 주석에 원칙이 있다.
- `src/ui/console-v2.css`: 표, 찾기 칸·깔때기 팝업(`.c-recent-*`, `.c-pop`), 펼친 상세(`.md-inline`), 좁은 화면 대응.
- `src/ui/SearchFilterBar.tsx`: 찾기 칸 + 깔때기 팝업 구성(§4-b 를 허락받으면 참고).

## 7. 확인 방법

1. 라이더 백오피스에서 다크·화이트 둘 다 대시보드, 라이더 관제, 라이더 찾기, 배송 찾기, 상담함, 수행료 조정을 연다.
2. 통합 백오피스(같은 `console.css` 를 쓰는 앱)를 열어 **바뀌지 않았는지** 확인한다.
3. 화면 문구, 표 칸, 메뉴가 그대로인지 확인한다. 바뀐 것은 색과 모양뿐이어야 한다.
4. 브라우저를 125%·150% 로 확대해 겹치는 곳이 없는지 본다.
