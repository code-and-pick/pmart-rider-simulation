## 1. 공통 원칙(라이더 시뮬레이터 `src/ui/theme.css` 머리 주석 그대로)

1. **바탕은 조용하게** — 짙은 회색 판 + 얇은 선, 그림자 없음. 색 배경으로 칸을 칠하지 않는다.
2. **색은 상태 점·숫자·왼쪽 띠에만.** 급한 것도 빨강 상자 대신 점 + 왼쪽 띠.
3. **글꼴 Pretendard**(패키지로 들여옴), 숫자는 고정폭(`font-variant-numeric: tabular-nums`).
4. **보라 금지** — 강조는 파랑 하나. 단계 색이 더 필요하면 청록 `#2dd4bf`·노랑 `#facc15`.
5. **설명 글을 덧붙여 해결하지 않는다** — 화면 자체가 읽히게(작은 11px 회색 글 쓰지 않기, 본문 13·보조 12 이상).

## 3. 바꿀 곳(우선순위 순)

### ① 글꼴 — 가장 효과 큼
- **지금**: `font-family` 맨 앞에 Pretendard 가 있지만 들여오지 않아서 실제로는 맑은 고딕이 그려진다.
- **요청**: `npm i pretendard@1.3.9 --save-exact`(OFL-1.1)를 설치하고 `main.tsx` 에 `import 'pretendard/dist/web/variable/pretendardvariable-dynamic-subset.css'` 를 넣는다. 글꼴은 `'Pretendard Variable', Pretendard, -apple-system, 'Apple SD Gothic Neo', 'Malgun Gothic', system-ui, sans-serif`, `letter-spacing: -0.1px`, `-webkit-font-smoothing: antialiased`.
- **참고**: 라이더 시뮬레이터 `src/main.tsx`, `src/ui/theme.css` 첫 규칙.

### ② 이상 없음 / 확인할 일 띠
- **지금**: 초록 배경이 전체 폭을 칠한다.
- **요청**: 이상이 없으면 판 색 바탕 + 1px 선 + 회색 점 + 보조 글 한 줄. 이상이 있으면 왼쪽 3px 색 띠(빨강/주황) + 판 색 바탕 + 항목 알약(옅은 판 색) 한 줄. 넘치면 "n건 더"로 펼친다.
- **참고**: 라이더 시뮬레이터 `src/ui/IssueBar.tsx`, `rider-board.css` 의 `.ib.ib-line`, `theme.css` 의 "확인할 일" 부분.

### ③ 상태 꼬리표 — 테두리 칩을 "● 글자"로
- **지금**: 지난 주문 카드마다 테두리 칩이 두 개씩 붙고(초록·빨강 테두리), 재고 목록에는 회색 "보관"·"복귀 대기" 칩이 있다.
- **요청**:
  - 상태는 `● 피킹 완료` 처럼 7px 점 + 12.5px 글자로 바꾼다. 점만 상태 색을 쓰고, 글자는 보조 색으로 둔다. 문제(취소·실패)일 때만 글자도 빨강으로 쓴다.
  - 한 줄에 상태가 둘이면 `● 피킹 완료 · ● 패킹 완료` 처럼 점으로 나눠 한 줄로 쓴다.
  - "작업자 확인 중" 같은 꼬리말은 흐린 보조 글로 둔다.
- **참고**: 라이더 시뮬레이터 `theme.css` 의 `.rb-badge`(점 + 글자), `console-v2.css` 의 `.rd-st`(최근 배송 상태).

### ④ 3D 현장 — 다크 화면에서 바닥만 튀는 것
- **지금**: 어두운 판 한가운데 밝은 회색 바닥·벽이 있어서, 화면에서 가장 밝은 곳이 정보가 아닌 바닥이다.
- **요청**: **다크 모드일 때만** 바닥·벽·통로 재질을 판 색 계열로 한두 단계 낮춘다. 구역 색(냉동 파랑·냉장 초록·상온 노랑·입고 주황)과 선반·작업자는 그대로 둔다. 화이트 모드는 지금 그대로 둔다.
  - 예: 바닥 `#2a2f37`, 벽 `#353b45` 반투명, 통로 선 `#4b5563`.
- **주의**: 라이더 쪽에서 지도 색을 반전시켜 어둡게 해 봤더니 "군대 지도 같다"는 말을 들었다. 너무 어둡게 하지 말고 "밝기만 낮춘" 느낌이 맞다.

### ⑤ 3D 구역 이름표·라벨 — 보라 빼기
- **지금**: 구역 이름표(냉동 A·냉장 B·상온 C~H·입고창고·패킹·입고·검수)가 보라 알약이다.
- **요청**:
  - 구역 이름표는 짙은 판 색(`#14171c` 92%) + 흰 글자 + 앞에 구역 색 점 하나로 바꾼다.
  - 선반 번호·PS-1 같은 작은 라벨은 지금 짙은 회색 그대로 둔다.
  - 경고 라벨(예: "고회전(시험) H01-01" 빨강)은 그대로 둔다. 급한 것만 색을 쓴다는 원칙에 맞다.

### ⑥ 오른쪽 칸 — 숫자 줄·주문 카드
- **숫자 줄**(열린 출고·피킹·패킹·랙·막힘):
  - 위아래 두 줄이 같은 모양이라 무엇이 다른지 안 보인다. 두 번째 줄 앞에 작은 제목(예: "지금 단계")을 붙이거나 한 줄로 합친다.
  - 숫자 22px/800 고정폭, 이름 12px 보조 색.
  - 0 인 칸은 숫자를 흐리게(라이더 쪽 `.fb-step.zero` 처럼) 해서 값이 있는 칸이 먼저 읽히게 한다.
- **진행 주문 카드**:
  - 왼쪽 노란 띠 + 단계 점(피킹·패킹·랙·배차·인계)은 좋다. 그대로 둔다.
  - 띠 색은 상태 색 규칙(진행 파랑·주의 주황·문제 빨강)에 맞추고, 노랑은 "가게에서" 단계에만 쓴다.
  - 오른쪽 위 "피킹 기다림" 회색 글은 그대로 둔다.
- **탭**(지난 주문·진행 중 작업·인계 확인·반납 번호): 테두리 알약 대신 밑줄 탭이나 회색 바탕 하나 위에 고른 탭만 판 색으로 둔다(라이더 쪽 `.an-seg`).
- **찾기 줄**: 날짜와 주문번호 입력칸을 왼쪽에 모으고, 새로고침 ↻ 은 버튼 모양으로 바꾼다. 라이더 쪽 찾기 칸 + 깔때기(`SearchFilterBar`)와 같은 높이(36px)로 맞춘다.

### ⑦ 왼쪽 메뉴·왼쪽 칸
- **두 개가 켜짐**: 지금 화면(예: 재고)과 "설정"이 동시에 파랗게 보인다. 고른 화면 하나만 켜지게 한다. 설정이 "열린 칸" 표시라면 다른 모양(점 등)으로 구분한다.
- **메뉴 글자**: 10px → 11~12px, 아이콘은 같은 굵기의 선 아이콘으로 맞추면 좋다(이모지 섞임 정리).
- **왼쪽 칸 빈 곳**: 실서버 모드에서 카드 한두 개 뒤 아래가 통째로 빈다. 칸 높이를 내용만큼으로 줄이고(그 자리는 3D 가 넓게 씀), 접기 버튼을 둔다.
- **화면 모드**: 아래 "밝게" 한 버튼을 "화면 [다크 | 화이트]" 고르기로 바꾼다. 화이트는 머리 줄·왼쪽 메뉴까지 밝게 한다.
  - 참고: 라이더 시뮬레이터 `App.tsx` 의 `c-rail-mode`, `theme.css` 의 "화이트 모드" 부분.
