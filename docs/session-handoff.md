## 0-1. 사용자와 일하는 방식 (꼭 지킬 것)
- 사용자에게 보이는 글은 **진행 안내까지 전부 한국어**.
- 커밋: 일지(`docs/worklog/YYYY-MM-DD.md`, 제목에 **실제 시각** — 커밋 전에 시계 확인) 없이 커밋하지 않는다. `git add` 는 경로 지정만(`-A` 금지). **PR 없이 main 에 바로 푸시.**
- 화면 확인은 Chrome 확장으로 **새 탭을 열어 보고 닫는다**(사용자 탭을 조종하지 않음). 화면 모드(다크·화이트, localStorage `rider-sim.theme`)를 바꿨으면 원래대로(다크) 돌려 둔다. Chrome 이 여러 개 연결돼 있으면 PC 5 Chrome("PC5")을 골라야 localhost 가 열린다.
- UI 는 **설명 글을 붙이지 말고 보면 알게** 다시 짠다(글자 크기 한 줄 규칙, 11px 회색 글 금지, HTML 차트, 얇은 표시).
- **보라 강조 금지**: 사용자가 넓은 메뉴·보라 시안(`ea3a524`)을 되돌렸다(`ea30b40`). 파랑·72px 아이콘 메뉴·기존 메뉴 이름 유지.
- 사용자가 새 화면이 싫다고 하면 태그 `before-rider-control-layout`(a6941f8)·`before-delivery-control-layout`(4f9fc78) 로 `git revert` 커밋(강제 이동 금지).

## 0-2. 지금 화면 구성 (2026-11-21)
- 왼쪽 72px 아이콘 메뉴(`src/app/App.tsx`): **라이더 관제**(기본) · **배송 관제** · **운영 현황**(예전 "목록 관제") · **분석** · **기록**, 아래에 화면 모드 다크·화이트 고르기.
- **라이더 관제**: `[라이더 목록 | 지도 | 라이더 상세]` + 아래 최근 배송. 백오피스 라이더 관제와 같게(사용자 2026-11-19 "똑같이 해봐").
- **배송 관제**: 위 흐름 막대(`FlowBar`) + `[배송 목록 | 지도 | 배송 상세(MapDetail)]`. 두 관제 맨 위에 "확인할 일" 한 줄 띠(`IssueBar`, 44px).
- **운영 현황**(`RiderControlPage.tsx`): 진행 중 주문 카드(`ActiveOrders`)·숫자 카드·라이더 표·최근 배송 표(`RecentDeliveries` — 왼쪽 찾기 칸 + 깔때기 팝업으로 상태 거르기, 줄을 누르면 아래로 펼침).
  - **배송을 누르면 배송 관제로 넘어가지 않는다**(2026-11-20 19:20 `6aec3a4`): 라이더 상세 최근 배송·라이더 표 진행 중 배송·진행 중 주문 카드 → `focus {id, n}` → 최근 배송 표가 찾기·거르기를 풀고 그 줄을 펼쳐 스크롤(최근 30건 밖이면 맨 아래에 붙임). 지도로는 "지도에서 보기" 단추만.
- **분석**(`AnalyzePage.tsx`·`analyze.css`·`timeChart.ts`): 기간(최근·하루·일주일) 시간대별 막대 → 막대를 누르면 배송 목록 → **배송번호를 누르면 목록 바로 아래에 `DeliveryDetail`(배송 흐름 | 주문 내역)**, 누른 줄은 왼쪽 띠(`tr.on`). 다시 누르거나 ✕ 로 닫음(2026-11-20 19:25 `c40589b`). 라이더별 배송 표(얇은 띠)·타임라인.
  - 분석 탭에는 "통합 검색"이 **원래 없었다**(사용자가 물어봐서 답함). "분석 맨 아래에 전체 배송 찾기 표를 붙일까요?" 제안만 했고 **사용자 답 없음 — 시작하지 않음**.
- **기록**: 주문 흐름(한 주문의 배송을 "1차 첫 배송 · 2차 재배송…"), 맨 위 구간별 평균, API 기록.
- **배송 상세**(`MapDetail`): 탭 상세·주문(직원용 주문 상세·원문 열람)·흐름(+제안 목록)·원래 상태. 배송 번호에는 늘 무슨 배송인지 붙임(고객 배송·전달 실패 반납 …).
- **지도 라이더**: 수단별 그림(`render/markers.ts`), 핀 80%(고른 것 92%). **실제 자리에서 옮기지 않는다** — 같은 자리면 겹친 채 그리고, 겹친 곳을 누르면 "누구?" 고르기 창(`2574064`). 다크 지도는 반전 대신 원래 지도를 살짝 낮춤.
- **쉬는 라이더**: 맡은 배송 없음 + 신규배차 꺼짐 = "쉬는 중 · 위치 공유 안 함"(회색, 지도에 안 그림). 실서버는 관제 응답 `locationShared`(tracking 0.12.0) 우선.
- **경보**: 라이더 찾는 중이면 "라이더 못 찾음"만(배송 지연 같이 안 띄움), 전달 실패 경보는 `FAILURE_REPORTED`(확정 전)만, 묶음 알약은 "확인 N".
- **찾기**: 주문번호·라이더 번호·ID — 하이픈·공백·별표 빼고 4자 이상 부분 일치(`RiderBoard.findTarget`).
- 배차 제안 출처 `FAILED_RETURN` = "원래 라이더 바로 배정"(dispatch 0.13.2 배포 대기, `a989a72`).

- MOCK `apiLog` 는 고리 버퍼라 오래 돌리는 시험에서 앞 기록이 밀려난다 → 시험은 `onApiCall` 듣개로 센다.
- 실행 기록의 시도 원인 값은 계약에 있는 값만(`'SYSTEM'` 없음 → `'AUTO'`).
- 결제 뒤 배차를 풀 때 `DeliveryAssignmentChanged` 를 내면 안 됨(계약상 그 사건이 아님).
- `RealWorld` 생성자의 네 번째 인자는 옵션 객체(`{fetch?, locator?}`).
- 브라우저가 POST 에 붙이는 Origin 을 게이트웨이가 본문 없는 403 으로 막음 → 개발 서버가 `/api` 요청의 Origin·Referer 를 지운다.
- 일지 제목 시각은 실제 시각으로(여러 번 바로잡음 — 커밋 전에 시계를 본다).
- 백그라운드 개발 서버는 PC 메모리가 부족하면 Claude Code 가 끌 수 있다(2026-11-17 발생). 끈 뒤 같은 포트를 다른 vite 프로세스가 잡고 있으면 그 프로세스를 끄고 띄운다.
